# Drive and Fight Wiki

English Roblox guide site for
[www.driveandfight.wiki](https://www.driveandfight.wiki).

The site covers the current official code, truck upgrades, trailers, weapons,
armor, skills, Air Drops, distance milestones, co-op roles, verified links, and
the route to a full run. The homepage uses a compact media hero and every
content page has sticky desktop wiki navigation plus a mobile menu.

## Local development

```bash
pnpm install
pnpm dev
```

Validate with `pnpm lint`, `pnpm exec tsc --noEmit`, `pnpm next:build`, and `pnpm build`.
